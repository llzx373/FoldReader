# 21 合集：顶格的分篇标题不能被并进上一段

- **现象**：文件是多篇拼接的合集，分篇标题**顶格**写（`【第二篇】作者：某某`），
  而正文段落是缩进的。
- **期望**：
  - 分篇标题保持独立一行、顶格；
  - 它**前后的空行必须保留**——在这本书里，这个空行是「顶格行不是续行」的**唯一**依据，
    删掉就等于把分篇标题并进了上一段。
- **档位**：STANDARD。
- **关键设计**：空行规整与段落重组**共用同一套边界判据**。原先只按「两侧有没有缩进」
  判空行冗余，于是「缩进段 → 空行 → 顶格标题」里的空行被判冗余删掉，
  下一步重组就按「上一段缩进起头 + 下一行顶格」把它并了。而且**原文的空行个数会影响结论**
  （3 个空行时「不并」、折成 1 个后「并」），直接不幂等。
  现在的规则：**空行只有在「下一行能自己站稳」时才冗余**（有缩进 / 是标题）。
- **来源**：一本真实的网文合集 TXT（3 篇拼接）实测暴露。
