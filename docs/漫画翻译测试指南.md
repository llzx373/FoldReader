# 漫画 AI 功能真机测试指南（M21–M23）

适用范围：OCR 引擎与扫描 PDF 文本层（M21）、漫画翻译 v1（M22）、漫画翻译 v2——
跨页气泡合并 / 气泡位置微调 / 视觉模型模式（M23）。

---

## 一、安装与三项必备设置

### 1. 安装 APK

`app/build/outputs/apk/release/FoldReader-release.apk`（`./gradlew :app:assembleRelease` 产出）。
仅支持 arm64-v8a / x86_64（M21 起放弃 32 位）。

> 注意：本地构建无正式签名密钥时回退 debug 签名。手机上若已装过其他渠道签名的
> FoldReader，需先卸载（数据会丢）再安装。

### 2. 导入 OCR 模型（漫画翻译与扫描 PDF 的前提）

模型不进 APK（R7），但**已随仓库提交在 `models/` 目录**，直接取这 5 个文件传到手机即可
（文件名不能改，导入按文件名匹配 + 全量 SHA-256 校验）：

| 文件 | 大小 | 用途 |
|---|---|---|
| `models/ch_PP-OCRv4_det_mobile.onnx` | 4.7MB | 文字检测（必需） |
| `models/ch_PP-OCRv4_rec_mobile.onnx` | 10.9MB | 中文识别（中日英混排覆盖最好，推荐） |
| `models/japan_PP-OCRv4_rec_mobile.onnx` | 9.8MB | 日文识别（测日漫必备） |
| `models/en_PP-OCRv4_rec_mobile.onnx` | 7.7MB | 英文识别（英文素材才需要） |
| `models/detector-v4-s_int8.onnx` | 11.1MB | 气泡检测（漫画翻译必需） |

上游来源（与 `core/ocr/ModelCatalog` 钉死的哈希一致，仓库文件已按此校验）：

- det/rec 四个：RapidOCR v3.9.2（modelscope.cn/models/RapidAI/RapidOCR）
- 气泡模型：huggingface.co/ogkalu/comic-text-and-bubble-detector（国内走 hf-mirror.com 同路径）

导入路径：App 内 **设置 → OCR 模型（离线识别）→ 模型管理 → 逐个「导入」**。
识别语言保持「自动」即可（自动优先中文模型，混排覆盖最好）；测纯日漫可切「日语」对比。

### 3. 配置 AI 服务

**设置 → AI 服务**：启用 → 选协议（OpenAI Chat / Responses / Anthropic）→
填 Base URL 与 API Key → 填模型名 → **连接测试**通过。

模型配置的回落关系（一处配置全场景可用的关键）：

- 「通用模型」是所有场景的兜底；
- 「翻译模型」未配置时，所有翻译场景（选中即译 / 章节翻译 / 全书翻译 / 漫画翻译）回落通用模型；
- 「视觉模型」未配置时，漫画视觉翻译同样**回落通用模型**——所以一个带视觉能力的通用模型
  （如 gpt-4o、qwen-vl 系列）只填「通用模型」一处即可全场景使用。
  回落的通用模型若实际不支持图像输入，会由服务商报错、在确认页按失败呈现，可重试或改配置。

### 4. 准备测试素材

- 一本**日漫** cbz/zip（竖版页，测 RTL 与常规翻译）
- 一部**条漫**（长图或切片，测跨页合并与滚动模式）
- 一本**扫描版 PDF**（无内嵌文字层，测 M21 OCR 文本层）

## 二、功能测试清单

### M21 扫描 PDF 文本层

1. 打开扫描 PDF → 菜单**不应**再出现「这是扫描件，暂不支持取字」（模型就绪后文本层装饰器挂上）。
2. 「搜索」能搜出页面文字并跳转。
3. 长按拖框能选中文字（可复制）。
4. 设置里切换识别语言后重新搜索，验证语言模型生效。

### M22 漫画翻译 v1

1. 打开日漫 → 菜单出现「译文」组（AI 未配置或模型未导入时整组消失——可先验证这个零变化）。
2. 「翻译本页」→ 首次弹**外发确认**（明示只外发文字、图片不上传）→ 确认页显示
   气泡数 / 字数 / token 估算，可临时切语言、改当次提示词 → 开始翻译，**流式逐气泡上屏**。
3. 三种视角：
   - 覆盖：译文贴气泡、随缩放平移、低置信气泡琥珀边框；
   - 对照：双页布局下同一页左原右译（不随 RTL 镜像）；
   - 气泡对照：面板逐条原文/译文，点条目页面对应气泡高亮。
4. 「翻译整卷」→ 确认页明示成本口径 → 通知栏进度，可**暂停/继续**；
   杀进程重进后断点续译（已译页跳过）。
5. 设置 → 术语表：加一条术语（如角色名），重译一页验证译法统一
   （漫画按书名主干跨卷共享系列术语，优先级 书 > 系列 > 全局）。
6. 合规检查：设置 → 外发历史有「漫画翻译」记录；删书后该书翻译产物一并清除。

### M23 漫画翻译 v2

1. **气泡微调**：菜单「调整气泡」→ 顶部提示条出现，全部气泡显示轮廓（未译页也有）→
   拖动气泡移动、拖右下角手柄缩放 → 松手即保存；「恢复自动位置」一键还原；
   翻页后新页同样可拖。**滚动模式下此入口不出现**（另一套坐标系，已知边界）。
2. **视觉翻译**：菜单「视觉翻译」→ 首次对这本书弹「**整页图片外发**」确认 →
   翻译后覆盖层直接出现（气泡框由视觉模型给出，不经本地 OCR）；
   外发历史记「漫画视觉翻译」并注明页图像；**换一本书会再弹一次确认**（逐书确认）。
3. **跨页合并**：找一页底部气泡被切断、下一页顶部是续段的条漫素材 → 翻译前一页 →
   切断的话应作为**整句**一次译出；翻到下一页，顶部原文续段应被底色盖掉（抹除条目）。
   已知边界：只在两页都未译时自动合并。
4. 一致性：微调过的气泡在覆盖层与「气泡对照」面板里位置一致。

## 三、重点关注的风险项（真机待验）

1. **int8 气泡模型兼容性**（最大风险）：`detector-v4-s_int8.onnx` 在 onnxruntime-mobile
   精简算子包下可能缺 Q/DQ 算子——首次「翻译本页」触发气泡识别时若直接报错或崩溃即此问题，
   请保留报错文本反馈（退路见 docs/AI功能需求与实施.md §风险）。
2. 覆盖层在缩放、翻页动画、双页对照翻页时的贴合同步观感。
3. OCR 单页耗时（目标 1600px，几秒级算正常）与视觉模式实际费用。
