# 构建与打包

本文说明如何从源码构建 FoldReader 并打出可分发的包。正式发布（打 tag、GitHub Secrets、Release 流水线）见 [发布流程.md](发布流程.md)。

---

## 一、前置要求

| 依赖 | 版本 |
| --- | --- |
| JDK | **25**（`gradle/gradle-daemon-jvm.properties` 固定了 daemon toolchain 为 25） |
| Android SDK Platform | `android-37.0`（targetSdk 37 为滚动版本，需要较新的 SDK） |
| Gradle | 9.7.1（wrapper 已内置，无需单独安装） |

在仓库根目录创建 `local.properties` 指向本地 SDK：

```properties
sdk.dir=/path/to/Android/Sdk
```

## 二、两个 flavor

`app/build.gradle.kts` 定义了 `models` 维度的两个 flavor，功能完全相同、包名与签名一致：

- **lite** —— 不带模型，包小；模型在「设置 → OCR 模型 → 模型管理」里自行下载导入。
- **full** —— 把仓库 `models/` 下的 5 个官方模型打进 assets，首次启动校验后铺到私有目录，装完即用。

任务名因此都带 flavor 前缀：`assembleDebug` / `testDebugUnitTest` 这类不带 flavor 的任务名是**歧义名**，直接跑会被 Gradle 拒绝。

另外，M21 引入 ONNX 推理后 APK 只打 **arm64-v8a + x86_64** 两种 ABI（放弃 32 位老设备控制包体）。

## 三、常用命令

```bash
./gradlew :app:assembleLiteDebug        # 构建 lite debug APK
./gradlew :app:assembleFullDebug        # 构建 full debug APK
./gradlew :app:testLiteDebugUnitTest    # 单元测试（CI 门禁跑这个；600+ 用例）
./gradlew :app:lintLiteDebug            # Lint
./gradlew :app:assembleRelease          # 构建两个 flavor 的 release APK（R8 + 资源压缩）
./gradlew :app:bundleRelease            # 构建 AAB
```

产物位置：

- `app/build/outputs/apk/lite/release/FoldReader-lite-release.apk`
- `app/build/outputs/apk/full/release/FoldReader-full-release.apk`

按发布流程的习惯，开发期测试包重命名为 `FoldReader-<版本>-<序号>-lite.apk` / `-full.apk`（序号取已有产物最大 +1）。

## 四、发布签名

release 构建的签名密钥按以下优先级读取：

1. 环境变量：`FOLDREADER_KEYSTORE_FILE`、`FOLDREADER_KEYSTORE_PASSWORD`、`FOLDREADER_KEY_ALIAS`、`FOLDREADER_KEY_PASSWORD`
2. 仓库根目录的 `key.properties`：

   ```properties
   storeFile=/absolute/path/to/release.jks
   storePassword=****
   keyAlias=****
   keyPassword=****
   ```

两者都不完整时会**回退到 debug 签名**，因此贡献者无需任何密钥即可构建 release 包做性能验证；debug 签名的产物不可分发给用户。正式发布流水线会强制要求正式密钥（见 [发布流程.md](发布流程.md)）。

> `key.properties`、`*.jks`、`*.keystore` 已在 `.gitignore` 中，请勿提交密钥。

## 五、版本号

`gradle.properties` 中的 `foldReader.versionCode` / `foldReader.versionName` 是本地默认值，可用 `-P` 覆盖：

```bash
./gradlew :app:assembleRelease -PfoldReader.versionCode=10200 -PfoldReader.versionName=1.2.0-1
```

开发期间**不主动递增版本号**：目标版本固定在 `gradle.properties`（当前 `1.2.0` / `10200`），本地与测试包一律用 `1.2.0-<开发序号>`。完整规则（versionCode 推导、tag 发布、预发布后缀）见 [发布流程.md](发布流程.md) 第二节。
