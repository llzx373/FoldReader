# FoldReader 需求与设计说明书

**专为折叠屏手机打造的小说阅读器**

| 项目 | 内容 |
|---|---|
| 文档版本 | v1.2 |
| 适用产品 | FoldReader（com.llzx373.foldreader） |
| 目标平台 | Android（minSdk 33 / targetSdk 37），以大折叠 + 阔折叠为核心目标设备 |
| 初期格式 | TXT；后续扩展 EPUB / MOBI / PDF 等 |
| 技术栈 | Kotlin + Jetpack Compose + Material Design 3 Expressive |

---

## 1. 产品定位与目标

### 1.1 定位
市面上绝大多数阅读器是按"直板手机"思维设计的：屏幕变大了，只是把页面拉伸。FoldReader 的核心理念是——**折叠屏展开后不是"更大的手机"，而是"一本打开的书"**。铰链是书脊，左右两屏是左右两页。

### 1.2 产品目标
1. **折叠形态下尽善尽美**：折叠、展开、悬停（半折）、旋转、跨屏流转，每种姿态都有精心设计的阅读体验，而非简单拉伸。
2. **先把 TXT 做到极致**：大文件秒开、章节自动识别、排版精美、翻页流畅。
3. **架构为格式扩展而生**：解析层抽象为格式引擎接口，后期接入 EPUB 等格式时 UI 与阅读核心零改动。

### 1.3 非目标（本期不做）
- 在线书城 / 网络书源
- 账号体系与**云同步**（书签、划线标注均本地存储）
- 社交、评论、社区功能
- PDF 重排、扫描版 OCR

## 2. 目标用户与核心场景

### 2.1 目标用户
- **大折叠**手机用户（华为 Mate X 系列、三星 Galaxy Z Fold 系列、荣耀/OPPO/vivo/小米大折叠）
- **阔折叠**手机用户（如华为 Pura X 等 16:10 宽内屏新形态）
- 重度 TXT 网文/小说读者，本地藏书量大，对阅读体验敏感
- 直板手机与竖折 Flip 为兼容降级目标，不做专门设计

### 2.2 核心使用场景

| 场景 | 设备姿态 | 用户诉求 |
|---|---|---|
| 通勤碎片阅读 | 折叠态（外屏/合拢单屏） | 单手操作，与普通手机一致的阅读体验 |
| 居家沉浸阅读 | 完全展开（约 8 英寸，接近平板） | **双页书式排版**，像读纸质书 |
| 床头/桌面免手持 | 悬停半折（约 90°，立于桌面） | 上半屏阅读，下半屏控制/自动翻页 |
| 折叠/展开切换中 | 姿态动态变化 | 阅读位置、字号、设置**无缝连续**，不跳页不丢失进度 |
| 大折叠横持 | 展开 + 横屏 | 双页宽幅排版，充分利用宽度 |

## 3. 折叠屏形态分析（设计的物理基础）

### 3.1 设备形态抽象
通过 Jetpack WindowManager 获取 `FoldingFeature`，抽象出以下状态：

| 状态 | 判定条件 | 典型设备 |
|---|---|---|
| 折叠态（CLOSED） | 无折叠特征或折叠特征完全合拢 | 外屏使用 |
| 展开态（FLAT） | `state = FLAT` | 展开的大内屏（大折叠约 4:3 / 阔折叠约 16:10） |
| 悬停态（HALF_OPENED） | `state = HALF_OPENED` | 半折立于桌面 |
| 铰链方向 | `orientation = VERTICAL / HORIZONTAL` | 左右书脊 / 上下翻盖 |

**阔折叠适配要点**：阔折叠内屏为宽幅 16:10 左右比例（介于手机与平板之间），展开态仍采用双页书式排版，但页宽较窄、行长取排版上限区间的下限；其铰链方向（VERTICAL/HORIZONTAL）与展开比例需以运行时 `FoldingFeature` 实测为准，不写死任何尺寸。

**无铰链宽屏设备**：直板手机/平板横屏等无折叠特征但宽度达 EXPANDED 的设备，默认降级为单页；提供"宽屏双页"用户开关（默认关），开启后按屏幕中缝均分双页。

### 3.2 铰链（折痕）避让
展开态下，铰链区域（`FoldingFeature.bounds`）存在物理折痕，文字落在折痕上严重影响阅读。布局必须：
- 将屏幕按铰链区域划分为**两个安全显示区**；
- 正文内容严格避开铰链区域；
- 铰链本身作为"书脊"视觉元素融入设计（阴影、中缝），而非回避的缺陷。

### 3.3 姿态连续性（Continuity）
折叠/展开切换时（Activity 不重建或重建后恢复）：
- 阅读进度（精确到字符偏移）必须保持，目标页内容尽量延续；
- 双页 ↔ 单页切换时，以"当前左页首字符"为锚点重新分页；
- 字号、主题、亮度等设置即时生效，无闪烁。

## 4. 设计语言：Material Design 3 Expressive

整体 UI 遵循 **Material Design 3 Expressive** 最新设计标准（Compose material3 1.4+，以 `MaterialExpressiveTheme` 落地），而非基础版 M3。

### 4.1 主题与动效基调
- **主题入口**：`MaterialExpressiveTheme` + `MotionScheme.expressive()`，全 App 动画采用弹簧物理（spring physics），杜绝生硬线性动画；
- **色彩**：外壳 UI（书架、设置、对话框）启用动态取色（Android 12+ 壁纸取色）；**阅读区是例外**——阅读主题（护眼绿/羊皮纸/纯黑等）为沉浸阅读服务，独立于系统动态取色，但阅读控制面板、菜单等覆盖层仍遵循 M3 Expressive 组件规范；
- **字体**：采用 Expressive emphasized 字阶，标题更粗更有表现张力；正文阅读排版规则仍按第 5 章排版引擎要求执行；
- **形状**：加大圆角的 Expressive 形状系统，书架封面、卡片、底部面板统一应用。

### 4.2 组件选型（Expressive 新组件优先）
| 场景 | 组件 |
|---|---|
| 书架导航 | `NavigationSuiteScaffold`（折叠态底部导航 / 展开态侧边导航，随窗宽自适应） |
| 书架浏览 | 网格 + `Carousel` 封面浏览；大标题可折叠 TopAppBar |
| 导入入口 | `FloatingActionButtonMenu`（展开含"本地导入"等操作） |
| 解析/加载 | 波浪形 `LoadingIndicator` / `WavyProgressIndicator` |
| 阅读设置面板 | `ButtonGroup`、`SplitButton`、带刻度停靠的 `Slider`、分段按钮（翻页方式/主题选择） |
| 底部控制栏 | 悬停态下半屏控制面板、阅读菜单均以 Expressive 底部面板形态呈现 |
| 对话框/提示 | Expressive 规格的 AlertDialog、Snackbar |

### 4.3 与阅读体验的边界
阅读正文区追求"无 UI"沉浸感，Expressive 的表现力集中在**外壳 UI 与控件层**；正文区的翻页动画（仿真/覆盖）手感与弹簧物理基调协调一致，但不套用组件动效。

## 5. 阅读界面设计（核心）

### 5.1 折叠态：单页模式
- 与常规手机阅读器一致：单栏正文、全屏沉浸、点击翻页/仿真翻页。
- 优化单手操作：翻页热区、底部控制栏布局按拇指可达区设计。

### 5.2 展开态：双页书式模式（标志性体验）
- 铰链左右各显示一页，合起来是"打开的一本书"：
  - **左屏 = 左页，右屏 = 右页**；翻页一次翻两页（书式语义）。
- 双页排版细节：
  - 左右页内侧（书脊侧）留白略大于外侧，模拟真实书籍装订；
  - 书脊中缝渲染柔和阴影渐变，增强立体感；
  - 页码、章节名分别置于左右页外侧页眉/页脚。
- 翻页动画：
  - 展开态默认**纸张仿真翻页**（右页向左翻动覆盖左页的书页动效）；
  - 实现模型：双页与单页共用**铰链旋转模型**——纸张绕竖直书脊轴（双页=中缝轴，对准分页线；单页=页左缘轴）整体旋转。双页走整程：前半程正面透视压缩、后半程页背（内容为目标跨页另半页的镜像）落到对侧页上，p=0/p=1 与静止态严格无缝；单页只走前半程：纸张转到垂直位（投影宽度为 0、屏上恰好全是目标页）即完成，落账无缝且自由边全程跟手（无后半程出屏不跟手问题）。两模式共享同一套动画时序（点击 tween 360ms、松手弹簧回弹/抛出）与拖拽进度语义，表现一致；
  - 可选：覆盖滑动、无动画、上下滚动（滚动模式下双页退化为双栏连续文本）。
- 用户可设置展开态强制单栏（宽幅单栏），满足不喜欢双页的用户。

### 5.3 悬停态：桌面模式（Tabletop）
- 上半屏：正文（单栏）；
- 下半屏：控制面板——
  - 翻页按钮、进度条/章节跳转；
  - 亮度、字号快捷调节；
  - **自动翻页**开关与速度（解放双手的"桌面阅读"场景）；
- 下半屏面板支持熄屏（屏幕下半变暗节能，AMOLED 友好）。

### 5.4 横竖屏
- 展开态横持：保持双页，页宽变宽，行长按排版舒适度上限（约 40 字符/行）约束，超出部分居中留白。横持时铰链相对窗口为水平方向，双页按屏幕中缝均分（左右等宽）。
- 折叠态横持：单栏宽幅，遵循同样的行长上限。

### 5.5 排版引擎要求
- 行长上限：中文每行 18–40 字可调（默认随屏宽自适应）；
- 首行缩进 2 字符、段落间距、行距、字距可调；
- 标点避头尾、两端对齐（中文排版基本功）；
- 支持字体导入（TTF/OTF）与系统字体；
- 页边距、书脊间距可视化调节。

### 5.6 阅读辅助功能
| 功能 | 说明 |
|---|---|
| 目录 | TXT 章节自动识别（正则规则库："第X章/卷/回"等，可自定义规则） |
| 进度 | 百分比 + 章节进度 + 全书剩余时间估算 |
| 书签 | 任意位置加书签（锚点精确到字符偏移，同页可有多条），列表管理（按创建时间排序），双页模式下左右页可分别添加 |
| 划线标注 | 长按选择文本划线（多色）并可附笔记；标注列表按章节分组；标注锚定字符偏移，姿态切换/重排版后位置不变；本地存储，不依赖云同步 |
| 跳转 | 按百分比、按章节、按书签跳转 |
| 搜索 | 全文搜索，结果按章节分组 |
| 夜间模式 | 随系统 + 手动；纯黑 AMOLED 主题 |
| 主题 | 预设护眼绿/羊皮纸/灰白等 5+ 主题，支持自定义背景色与文字色 |
| 亮度 | 应用内独立亮度，下拉手势调节 |
| 自动翻页 | 按时间滚动/翻页，悬停态重点功能 |
| 翻页方式 | 仿真/覆盖/无动画/上下滚动，点击热区与音量键翻页可配 |
| 屏幕常亮 | 阅读界面保持唤醒（可关） |

## 6. 功能需求（非阅读界面）

### 6.1 书架
- 本地书架：封面（TXT 自动生成书脊式封面）、书名、进度、最近阅读排序；
- 网格/列表两种视图；展开态下自适应多列；
- 批量管理：删除、分组（v1.1）。

### 6.2 TXT 导入与解析
- 来源（仅本地，不做 WiFi 传书 / 网络导入）：
  - 系统文件选择器（SAF）从书架主动导入；
  - **"打开方式"绑定**：注册 `VIEW` Intent（`text/plain`，`content` / `file` scheme），用户在其他 App（文件管理器、微信、邮件等）选择"用 FoldReader 打开"时直接导入并进入阅读；
  - 外部打开的书籍自动进入书架（同一文件 Uri 去重，重命名/移动后以内容哈希兜底识别）；
- 编码自动检测：UTF-8 / UTF-16 / **GBK / GB18030**（国内 TXT 重中之重）/ Big5；
- 大文件处理：
  - 100MB+ TXT 秒开：不整文件载入内存，按字节偏移**懒加载 + 滑动窗口缓存**；
  - 章节索引后台异步建立，建立期间可直接阅读；
- 智能清理选项：去空行、去广告行（正则替换规则，v1.1）、繁简转换（v1.1）。

### 6.3 阅读历史与进度
- 每本书记录：字符偏移进度、阅读时长、最后阅读时间；
- 打开书籍自动回到上次位置；
- 书签与划线标注随书籍记录，全部本地存储（Room），支持按章节浏览与跳转、编辑笔记、删除。

### 6.4 设置
- 全局默认阅读偏好 = **新书的初始**字号/主题/翻页方式；每本书首次打开时拷贝全局默认，之后独立演化（每书偏好独立存储）；
- 翻页热区、音量键、手势自定义；
- 备份与恢复（书架数据、设置，本地导出，v1.1）。

## 8. 技术架构设计

### 8.1 总体架构
单层 App 模块起步，包结构按**特性 + 分层**划分，遵循 MVVM + 单向数据流：

```
com.llzx373.foldreader
├── core/
│   ├── format/          # 格式引擎抽象（BookParser / BookContent / Chapter）
│   │   └── txt/         # TXT 实现：编码检测、章节切分、窗口化文本读取
│   ├── reader/          # 排版分页引擎（Paginator：文本 → 页列表）
│   ├── foldable/        # 折叠状态感知（FoldingState / Posture / 铰链区域）
│   └── data/            # Room（书架/进度/书签）+ DataStore（设置）
├── feature/
│   ├── bookshelf/       # 书架
│   ├── reader/          # 阅读器（单页/双页/悬停三态 UI + 手势 + 动画）
│   ├── importer/        # 书籍导入
│   └── settings/        # 设置
└── ui/theme/            # 主题
```

### 8.2 关键模块设计

**（1）格式引擎抽象（为后期扩展预留）**
```kotlin
interface BookParser {
    suspend fun parseMeta(uri: Uri): BookMeta
    suspend fun parseChapters(uri: Uri): List<Chapter>
    fun openContent(uri: Uri): BookContent   // 随机访问的文本源
}
interface BookContent {
    val charCount: Long
    suspend fun read(range: LongRange): String  // 按字符偏移窗口读取
}
```
后期 EPUB 只需新增 `core/format/epub` 实现同一接口。

**（2）TXT 窗口化读取**
- 文件按检测编码建立"字节偏移 → 字符偏移"映射索引（Room 持久化，按文件长度 + 内容哈希校验失效）；
- 索引后台增量建立，建立期间可直接阅读（读取仅等待所需数据块就绪，不阻塞全文索引）；
- 阅读时仅解码当前页 ± 若干页窗口，内存占用与文件大小解耦。

**（3）分页引擎 Paginator**
- 输入：文本窗口、页面尺寸（px）、排版参数（字号/行距/边距）；
- 输出：`List<Page>`（每页 = 字符区间 + 行布局）；
- 基于 `StaticLayout` 度量；页边界索引（每页字符区间）按（书籍 + 排版参数哈希 + 视口尺寸）磁盘持久化，行布局由内存 LRU 按需重度量；
- 双页模式下左右页共用同一分页流，仅是相邻两页（单一 Paginator，页宽取左右安全区较小值）。

**（4）折叠感知 FoldableState**
- 以 `WindowInfoTracker` Flow 封装 `FoldingFeature`；
- 输出：`{ posture: CLOSED|FLAT|HALF_OPENED, hingeBounds: Rect?, hingeOrientation }`；
- 阅读界面以此为一级输入决定布局模式，配合 `calculateWindowSizeClass` 做宽度兜底。

**（5）状态连续性**
- 进度锚点 = 当前页首字符偏移（Long），与布局无关；
- 姿态变化 → 以锚点重新分页 → 定位到包含锚点的页，天然无丢失。

### 8.3 依赖选型

| 用途 | 依赖 |
|---|---|
| UI | Jetpack Compose BOM + Material 3 **1.5.0+**（Expressive API 自 1.5.0 起公开：`MaterialExpressiveTheme`、`MotionScheme`、ButtonGroup、LoadingIndicator 等；需显式覆盖 BOM 版本） |
| 折叠屏感知 | `androidx.window:window` |
| 自适应布局 | `androidx.compose.material3.adaptive:adaptive*` |
| 架构 | lifecycle-viewmodel-compose、navigation-compose、kotlinx-coroutines |
| 本地存储 | Room（书架/进度/书签/章节索引）、DataStore Preferences（设置） |

### 8.4 Manifest / 系统适配
- `android:configChanges="orientation|screenSize|screenLayout|smallestScreenSize|keyboardHidden"`：折叠展开不重建 Activity；
- `android:resizeableActivity="true"`、支持多窗口/分屏；
- 阅读页 `keepScreenOn`、亮度控制、沉浸模式。

## 10. 风险与开放问题

| 项 | 说明 | 对策 |
|---|---|---|
| 仿真翻页性能 | 展开态大幅面双页仿真动画渲染压力大 | 预渲染 + 降级方案（覆盖滑动）|
| material3 1.5.0 为 alpha | Expressive API 仅在 1.5.0+ 公开，当前依赖 alpha 版，API 可能变动 | 锁定版本、升级前回归验证；稳定版发布后及时跟进 |
| 编码误判 | GBK/UTF-8 混合文件乱码 | 检测置信度 + 用户手动切换入口（书籍详情/阅读菜单可切换编码）|
| 章节识别失败 | 无规律 TXT（无"第X章"）| 规则库 + 自定义正则（设置页维护）+ 纯进度模式兜底 |
| 厂商折叠差异 | 各品牌铰链上报行为不一致 | 以 WindowManager 为准 + 真机矩阵测试 |
| 竖折（Flip）设备 | 展开仅手机大小，无双屏 | 按宽度 WindowSizeClass 优雅降级为单页 |
| 清洗版与原版的边界 | 同一文件可导入"原版+清洗版"两本，按 fileUri 查询时 LIMIT 1 可能取到另一本 | 内容自洽（索引键=bookId），可接受；清洗版书籍固定 UTF-8，不再提供编码切换 |

**已决议的产品决策（v1.0 定稿）：**
1. **设备范围**：聚焦大折叠 + 阔折叠；直板与竖折 Flip 仅做兼容降级，不专门设计。
2. **书籍来源**：仅本地文件导入（SAF）+"打开方式"绑定（其他 App 用 FoldReader 打开 TXT）；不做 WiFi 传书 / 网络导入。
3. **数据与功能**：不做云同步，所有数据本地存储；书签与划线标注（含笔记）列入 v1.0 范围。

**已决议的产品决策（v1.2 增补）：**
4. **宽屏双页**：无铰链宽屏设备（直板/平板横屏）默认单页，"宽屏双页"开关可选开启（设置页）。
5. **书签粒度**：任意位置加书签，锚点精确到字符偏移，同页可多条。
6. **每书偏好**：全局默认偏好仅作新书初始值，之后每书独立演化（book_prefs 表）。
7. **横持双页**：展开态横持（铰链相对窗口为水平）保持双页，按屏幕中缝均分。
8. **右栏摄像头避让**：双页模式可选"右栏下移一行"（设置页，全局开关）：奇数序页
   （跨页右页）分页减容一行、渲染顶端下移一行高，避开内屏摄像头；滚动模式不适用。
