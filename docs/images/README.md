## 采集清单

| 文件名 | 内容 | 建议尺寸 |
| --- | --- | --- |
| `01-bookshelf.png` | 书架网格 + 自动生成的封面；最好包含分组或封面就绪角标 | 1080 × 2400（竖屏） |
| `02-dual-page.png` | **展开态双页书模式**：体现铰链书脊阴影与靠书脊侧的加宽页边距 | 横屏，宽度 ≥ 1440 |

## 采集要求

- **必须来自真机或模拟器的折叠屏形态。** 双页书模式与桌面模式是本项目最主要的卖点，这两张图不能用直板机截图代替。
- 用 `adb exec-out screencap -p > 01-bookshelf.png` 抓取整屏；不要用手机自带截屏后裁切，避免多出状态栏圆角差异。
- 截图里的书籍内容请使用**无版权争议**的文本（公版书或自建测试文本）。仓库根目录被 gitignore 的 `f30/` 是历史测试截图，其中含已删除功能的中间帧，不要直接取用。
- 图片命名与上表严格一致，README 的引用路径依赖文件名。
- 单张控制在 500 KB 以内，必要时用 `pngquant` 或 `oxipng` 压缩。
