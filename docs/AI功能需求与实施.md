## 1. 总则

### 1.1 核心模式

> **AI 产出规则 / 配置 / 元数据 / 旁挂副本 → 用户预览确认 → 本地确定性执行。**

- AI 不进入任何运行期路径：阅读、分页、清洗、搜索的执行逻辑与无 AI 时逐字节一致；
- 每个 AI 产出都可预览、可推翻、可删除；推翻后系统行为回到现状；
- 沿用「宁可漏不可错」的确定性哲学（与规则库识别、SAF 降级同一口径）：
  模型输出畸形一律丢弃，解析失败即该次失败，绝不让半成品进入存储；
- 正文外发逐次明示，成本按用户主动动作结算；
- **提示词透明**：内置系统提示词全文可在设置页只读查看；按页翻译支持当次临时修改。

### 1.2 范围

| 做 | 不做 / 移出 |
| --- | --- |
| 整理类 AI：章节规则、清洗配方、元数据补全、AI 校对 | 前文回顾、选中即问、人物关系图谱（内容理解类，无限期后置） |
| 文本翻译：选段 / 按页 / 单章（块）/ 全书，三种对照视角 | 在线书城 / 书源、账号体系、社交 |
| 漫画翻译：本地 OCR + LLM 翻译 + 覆盖层，按页 / 整卷 / 视觉模式 | 在线 OCR / 云识别（识别永远在本机） |
| 阅读辅助：章节摘要、全书大纲、问书（限已读范围）、划词解释 | 端侧 LLM 推理（依赖门槛过不了） |
| 扫描版 PDF 文本层（OCR 的第二个消费者） | 词级在线词典、机器翻译专用 API（一律走用户配置的 LLM） |
| 非 AI 前置：TTS 听书、人物出场索引、本地 StarDict 词典 | 任意形式的静默外发（含崩溃上报、统计埋点） |

### 1.3 未配置时行为

- `aiConfigured()` = 总开关开 ∧ base URL 非空 ∧ 有 API key；不满足时**所有 AI 入口不渲染**
  （不是置灰），界面与无此功能时一致；
- `AppContainer` 中 `aiProvider()` 返回 null，`OkHttpClient` 不创建、不建立任何连接；
- 抓包应零请求；本地词典、OCR 文本层等**离线能力不受影响**（不依赖 AI 配置）。

## 2. 技术底座（M14，一切 AI 功能的前置）

### 2.1 模块结构

```
core/ai/
├── AiProvider.kt              # interface chat(messages, model): Flow<String>（SSE 文本增量）
├── AiConfig.kt                # AiProtocol（三协议）/ AiTargetLang（8 语言）/ AiConfig
├── AiMessage.kt               # 内容块：Text / Image（图片仅 USER 消息）
├── AiError.kt                 # 超时/限流/额度/认证/网络不可达 → 可读文案
├── AiProviderFactory.kt       # 按配置建 Provider；共用惰性 OkHttpClient 与超时策略
├── sse/SseParser.kt           # SSE 行流解析（纯 JVM）
├── openai/ChatCompletionsProvider.kt
├── openai/ResponsesProvider.kt
├── anthropic/AnthropicProvider.kt
├── prompt/                    # 13 条系统提示词 + 输出解析（纯 JVM，单测锁定）
├── gate/AiContentGate.kt      # 外发台账（JSON 文件，上限 500 条）
└── android/
    ├── CredentialStore.kt     # Android Keystore AES/GCM 加密的 key 存取
    └── ModelManager.kt        # OCR 模型 SAF 导入 / 全量 SHA-256 校验 / 删除 / 自定义槽位
```

装配纪律：`core/ai/` 与 `core/ai/prompt/` 不引用 `android.*`，可在 JVM 单测直接跑；
Android 依赖全部收在 `core/ai/android/`。

### 2.2 三协议与传输

| 协议 | 端点 | 备注 |
| --- | --- | --- |
| OpenAI Chat Completions | `POST {base}/chat/completions` | 默认协议，兼容面最广（DeepSeek / 通义 / 多数自建网关） |
| OpenAI Responses | `POST {base}/responses` | 新版 Responses API |
| Anthropic Messages | `POST {base}/messages` | `anthropic-version` 头，SSE 事件映射独立 |

- 传输统一走 OkHttp 单例（与 WebDAV 备份共用 `sharedOkHttpClient`），SSE 流式；
- 三协议的差异只在请求体构造与「SSE 事件 → 文本增量」映射，各自收敛在一个文件内；
- 取消流式请求会同步中断底层 HTTP 调用；
- **测试**：MockWebServer 端到端锁定三协议（正常增量 / 粘包 / 中途断流 / 429 / 非 200 错误体），
  不依赖真机与外网；另有一组读 `.env` 的真实服务商冒烟用例（未配置时自动跳过）。

### 2.4 凭据与外发合规

- **凭据**：API key 经 Android Keystore AES/GCM 加密后存私有 SharedPreferences；不进备份、
  不写诊断日志、不出现在崩溃报告与 `dumpsys`（与 PDF 密码、WebDAV 密码同一口径）。
- **首次外发一次性确认**（每类功能一个偏好，确认后不再弹）：

  | 偏好 | 覆盖范围 | 确认页明示内容 |
  | --- | --- | --- |
  | `aiChapterRuleConfirmed` | 章节规则生成 | 服务商地址 + 采样标题行范围 |
  | `aiCleanRecipeConfirmed` | 清洗配方推荐 | 服务商地址 + 采样字符数 |
  | `aiMetadataConfirmed` | 元数据补全（单书/批量共用） | 服务商地址 + 开头采样范围 |
  | `aiTranslationConfirmed` | 选中即译 / 按页 / 单章 | 服务商地址 + 仅外发选中或本页文字 |
  | `aiProofreadConfirmed` | AI 校对 | 服务商地址 + 全书字数 + token 估算 |
  | `aiSummaryConfirmed` | 章节摘要（预生成/章行共用） | 服务商地址 + 全书正文分批外发 + 成本估算 |
  | `aiQaConfirmed` | 问书 | 服务商地址 + 本次上下文范围（前序摘要 + 当前章） |
  | `aiExplainConfirmed` | 划词解释 | 服务商地址 + 仅外发选中的词与上下文 |
  | `aiComicTranslateConfirmed` | 漫画翻译（文本模式） | 明示**只外发气泡文字、图片不上传** |
  | `aiComicVisionConfirmedBooks` | 漫画视觉翻译（**逐书**） | 明示**整页图片外发** + 页数 + 成本 + 限速 |

- **外发台账** `AiContentGate`：每次外发记 `(时间, 功能, 范围, 估算 token)`，
  上限 500 条、超出丢最旧；文件损坏按空列表处理，绝不抛给调用方。
  设置页「外发历史」可查；WebDAV 备份也复用同一台账（feature=WebDAV 备份，token 记 0）。

### 2.6 成本口径

- token ≈ 字符数 ÷ 2（中文粗估）；金额 = token ÷ 1,000,000 × 单价；
- 漫画视觉模式按每页 ≈10K token 粗估（长边 1024px JPEG q85 ≈150KB → base64 ÷ 16）；
- 确认页展示「字数 → token → 金额」，并标注「实际以服务商账单为准」；
- 已译单位不重复外发（断点续译），确认页显示已有进度。

### 2.7 后台队列与前台服务

四个进程级队列共用同一骨架（Channel + 单协程串行、单位间让出、指数退避重试、
断点续做跳 done、暂停/恢复/按书取消、`StateFlow` 进度），各自配一个前台服务：

| 队列 | 服务 | 通知 ID（进度/完成） | 触发 |
| --- | --- | --- | --- |
| `BookTranslationQueue` | `TranslationService` | 43 / 44 | 「翻译全书」入队；读到未译单位自动插队 |
| `ComicTranslationQueue` | `ComicTranslationService` | 45 / 46 | 「翻译整卷 / 视觉整卷」 |
| `BookSummaryQueue` | `SummaryService` | 47 / 48 | 「预生成摘要」 |
| （TTS） | `TtsPlaybackService` | 42 | 朗读 |

单条失败不再终止整个队列：失败记 `failed` 后继续，重入队只重跑失败项。

## 3. 整理类 AI（只出规则 / 配置 / 元数据，不碰正文）

### 3.1 章节规则生成

**痛点**：无规律 TXT（合集、翻译体）章节识别失败后退化为纯进度跳转，是死路。

**流程**：

1. 入口：目录面板「未识别到章节」分支、书籍详情页（均仅 TXT + AI 已配置）；
2. 本地用现有章节扫描器粗筛「疑似标题行」候选集（≤300 行，非全书）；
3. 发给通用模型，返回 1–3 条候选正则 + 说明；
4. 逐条在本地跑真实切分预览：章节数、前 20 个标题、异常标记（超长章 / 空章 / 首章前孤儿文本）；
5. 用户选一条 → 存为该书的**自定义章节规则**（复用既有数据结构）→ 自动重建目录。

**另有一条零 AI 路径**：长按正文选中一行 →「章节规则」→ 本地合成候选正则
（`ChapterRuleSynthesizer`）→ 同一套试切预览 → 保存。全程不外发，与本节共用预览与重建链路。

**落点**：`feature/bookshelf/ChapterRuleAiDialog` / `ChapterRuleAiViewModel`、
`feature/reader/ChapterRuleFromSelection*`、`core/format/ChapterRulePreview`。

### 3.2 清洗配方推荐

**流程**：

1. 入口：「智能整理」对话框（仅 AI 已配置时显示）；
2. 采样头 2KB + 中 2KB + 尾 2KB（`CleanSampleSampler`，整行对齐、结果确定）；
3. 模型返回：建议开关覆盖（映射 `CleanToggles.ENTRIES`，未知 key 丢弃）+ 0–3 条广告正则
   （编译不过或空白丢弃）+ 一段问题说明；
4. 落成一份普通 `CleanProfile`（标准档为基线，CUSTOM 档），回到对话框后照常走
   **预览报告 → 确认 → 物化**。

**红线**：AI 不进清洗执行路径。`NovelCleaner` 与规则文件零改动，幂等性与测试集不受影响；
手动改选档位或繁简即放弃该配方。

### 3.3 元数据补全 + 智能分组

- 入口：书籍详情「AI 补全信息」（单书）、书架多选「AI 补全信息」（批量，串行 + 进度 + 可取消）；
  仅 TXT + AI 已配置；
- 采样源文件前 16KB（`MetadataHeadSampler`，4096 字上限、整行对齐、不整本加载）；
- 模型返回作者 / 简介 / 题材标签（固定枚举 `GenreTags` 十项，未知标签丢弃）；
- **只补「当前为空且未被用户锁定」的字段**：已有值（包括 AI 此前填的）一律不动；
- 来源标记 `metaSource` 逐字段编码（`author:ai,genre:user`）；AI 填的字段在详情页标
  「AI 生成」；用户手动编辑后打 `user` 标（含主动清空），此后单本与批量都永不再写该字段；
- 题材标签是规则版「按题材分组」的输入（纯规则，不走 AI）。

### 3.4 AI 校对

- 入口：书籍详情「AI 校对」（仅 TXT + AI 已配置）；
- 按翻译单位切块逐单位送检（通用模型，每单位 90s 超时，流异常或解析失败整体重试一次后
  记失败单位继续）；
- 输出契约：JSON 数组（`offset` / `length` / `original` / `suggestion` / `type=typo|grammar`），
  区间越界允许就近重定位一次，原文不符 / 空建议 / 原文=建议逐条丢弃，按 offset 去重升序、
  上限 50 条；
- 结果**只落成批注**（橙色高亮，note = `【AI 校对·类型】「原文」→「建议」`），
  **正文一个字节不动**；重跑先清上一轮校对批注；
- 校对对话框按「原文→建议」合并成逐条确认列表，勾选后「生成清洗配方」转成**纯替换规则**
  （`CleanProfile.replacements`，`NovelCleaner` 管线最前 `ReplacementSink`），带进
  「智能整理」走既有预览 / 确认 / 物化链路，不新增执行路径。

## 4. 文本翻译

### 4.1 译本即副本 + 翻译单位

```
一本书
├── 原文（不动一个字节）
└── 译本 filesDir/translations/<bookId>/<lang>/
      ├── units.json            单位清单（章或块）
      ├── unit_<index>.json     段落结构化译文（供段落对照直接使用）
      ├── content.txt           未译单位占位入流，保证单位对齐
      └── content.toc           与原文共用章节边界；无章节书生成伪目录
```

- **单位 = 章或块**：有章节的书按章；整本无章节、或单章超阈值（约 4000 字）时按段落边界
  切块（2000–4000 字 / 块，块不切段落，单段超长独立成块，首尾与章间孤儿文本纳入，
  保证全书无遗漏无重叠）；
- 翻译不跨单位是硬约束；单位重译只作废该单位；
- 模式切换按「单位号 + 单位内进度比例」定位，原文与译文各记各的锚点、互不换算；
- 译本走同一条分页管线，双页 / 仿真 / 主题自动可用；译文模式下标注写入 / 书签 / 选字翻译 /
  TTS 全部禁用（锚点是原文坐标系），复制保留。

### 4.2 选中即译（M18）

- 长按选字 → 选区操作条「翻译」（AI 已配置才出现）；
- 底部卡片**流式**显示译文（含源文摘抄）；源语言自动检测，目标语言默认取设置，卡片上可临时换；
- 「存为批注」锚定原选区偏移（默认黄色高亮）。

### 4.3 按页翻译（M19）

- 阅读菜单「翻译本页」：当前页（双页模式下为整个跨页）正文即时翻译；
- 发起前确认页：范围字数 + token 估算 + 目标语言临时切换 + **当次临时提示词**；
- 结果在「原文段 / 译文段」对照面板里**流式**追加（`PartialJsonArray` 提取已闭合段落），
  收尾校验段落数不一致即失败可重试；
- **不落译本副本**——需要沉淀时用「翻译本章」。

### 4.4 单章（块）翻译

- 阅读菜单「翻译本章」（无章节书显示「翻译本节」）；目录面板每章 / 块状态：
  未译 / 翻译中 / 已译 / 已译 x/n / 失败；
- 后台协程翻译，不阻塞阅读；译完该单位即可切换视角；
- 单章可重译（换模型 / 改目标语言 / 不满意），只作废该章覆盖的单位。

### 4.5 全书批量翻译

- 入口：书籍详情「翻译全书」（仅文本格式 + AI 已配置）；
- 确认页：目标语言（8 选 1，默认取设置）、全书字符数 → token → 金额（单价可当场改并写回）、
  断点续做提示；
- 队列串行、单位间让出、失败退避重试、断点续译、暂停 / 恢复 / 按书取消；
- 前台服务进度通知；**阅读到未译单位且该书在队列中时自动插队**。

### 4.6 三种视角

| 视角 | 可用条件 | 行为 |
| --- | --- | --- |
| 1 原文 / 译文切换 | 目标语言已有译本 | 整书正文模式切换，按单位号 + 比例重定位 |
| 2 双页对照 | 双页翻页布局 + 已有译本 | 左页原文、右页译本（第二个 Paginator）；翻页以左页为准，右页按单位追齐 + 单位内比例漂移；单页 / 悬停 / 滚动自动退出 |
| 3 段落对照 | 滚动模式 + 已有译本 | 一段原文 + 一段译文小卡片（背景 5% 文字色）；单位粒度懒加载 + LRU 24 单位；段对段映射直接取落盘结构化段落 |

### 4.7 术语表

- `glossary_terms` 三层级同表：`scope=global`（ownerKey 空）/ `series`（漫画系列）/
  `book`（bookId）；
- 注入优先级 **书 > 系列 > 全局**，同 source 高层级覆盖低层级；
- 候选双来源：人物出场索引 Top20、前 3 个单位翻译后的模型回填（`GlossaryBackfillPrompt`）；
  **候选 `confirmed=false` 不参与注入**，经 UI 确认后才生效；人物候选只有原名，确认时补填译法；
- 术语表 UI：确认 / 否决候选、全局表增删、单书表、漫画系列 Tab（有 seriesKey 的调用点才显示）。

### 4.8 章节摘要

- 入口：书籍详情「预生成摘要」（确认页明示外发范围 + 成本 + 已有 done 计数断点续做）；
  目录面板章行状态与「摘要」查看 / 「生成摘要」；
- `BookSummaryQueue` 复用翻译队列骨架，单位划分与翻译单位完全一致；
- 摘要 150–300 字纯文本、不评论、不剧透本章之外；落 `chapter_summaries`
  （状态机 pending / summarizing / done / failed + 单位标题快照，随书级联）。

### 4.9 全书大纲

- 入口：目录面板顶部「大纲」视图；
- 把摘要链聚合成 3–8 阶段大纲，标注章节范围，只依据摘要不虚构；
- 落 `book_outlines`（记录聚合时摘要条数，链变长提示可重新生成）。

### 4.10 问书

- 入口：阅读菜单翻译组「问书」（仅 AI 已配置且原文视角）；
- 上下文 = 当前单位之前的 done 摘要链（= 限已读范围）+ 当前章正文；
  超长时「摘要全保留、当前章截头」（尾部 = 最近情节）；组装是纯 JVM 函数 `BookQaContext`；
- 提问页常驻明示外发范围；回答流式上屏，prompt 要求以《章节标题》标注出处、
  上下文不足明说、不剧透当前章之后。

## 5. OCR 与漫画翻译

### 5.1 OCR 引擎与模型

`core/ocr/` 一次建设、两处消费（扫描 PDF 文本层、漫画翻译）。

| 槽位 | 文件 | 用途 | 钉版 |
| --- | --- | --- | --- |
| det | `ch_PP-OCRv4_det_mobile.onnx` | 文字行检测（中/英/日通用） | SHA-256 ✓ |
| rec_ch | `ch_PP-OCRv4_rec_mobile.onnx` | 中文识别 | ✓ |
| rec_en | `en_PP-OCRv4_rec_mobile.onnx` | 英文识别 | ✓ |
| rec_ja | `japan_PP-OCRv4_rec_mobile.onnx` | 日文识别 | ✓ |
| bubble | `detector-v4-s_int8.onnx` | RT-DETR-v2 气泡检测 | ✓ |
| inpaint | `lama.onnx` | 气泡抹除（可选） | ✗（自定义槽位） |

- 模型不进 APK：full flavor 自带 5 个官方模型（首启铺到 `filesDir/models/` 并过一遍哈希），
  lite flavor 由用户下载后经 SAF 导入（按文件名匹配清单 → 流式全量 SHA-256 → 落盘）；
- 自定义 `.onnx` 可进任意槽位，落 `<id>.custom.onnx`、**优先生效**，可单独删除回落官方；
- 识别词典（ppocr_keys_v1 / en_dict / japan_dict）随 APK 打包（必须与模型类别表一致）；
- NNAPI 硬件加速开关默认关（驱动质量因设备而异），改动即时作废会话重建；GPU EP 已评审排除。

### 5.2 扫描版 PDF 文本层

- `OcrTextLayerSource` 装饰页式来源：**有内嵌文本层先走原生**，拿不到才逐页 OCR；
- 结果按页缓存 `filesDir/pdf_ocr/<bookId>/<page>.ocr.json`；
- 解锁全文搜索与拖框选字，坐标与页内锚点同一归一化体系；
- 模型未就绪时行为与原来源完全一致（选字退自由框选、搜索空结果），入口天然缺席；
- 裁边（M32）不影响 OCR 缓存坐标系（OCR 取图刻意保持原页渲染）。

### 5.3 漫画页级管线

```
页位图（PagedImageSource）
 → [本地] RT-DETR 气泡检测 + 页级 OCR（det → rec）+ 行归并 → 带坐标文本块
     缓存 filesDir/comic_translate/<bookId>/<page>.ocr.json
 → [云端] LLM 流式翻译（注入术语表 + 同页气泡上下文）
 → 覆盖层 filesDir/comic_translate/<bookId>/<page>.<lang>.json
```

- OCR 缓存与译文分文件：换模型 / 改提示词重译不必重跑 OCR；
- 翻译请求要求气泡一一对应、数量必须与输入一致，校验失败整页重试一次；
- 流式：`PartialJsonArray` 逐气泡提取已闭合译文，逐个上屏；
- **按页**：确认页（气泡数 / 字数 / token 估算 / 目标语言 / 当次临时提示词）→ 流式；
- **整卷**：同一队列骨架（断点续译、退避、暂停/恢复、前台服务），页间隔 200ms 限速；
- 闸门：漫画格式 + AI 已配置 + 气泡与识别模型均已导入，否则整组菜单不出现。

### 5.4 三种视角与观感

- **覆盖层**：气泡位置铺采样底色（外周像素逐通道中位数抗文字噪点），译文随缩放 / 平移贴页；
  低置信气泡琥珀边框；可切「原文 / 译文 / 对照」三档；
- **双页对照**：同一页左原图、右译文覆盖层，页序号同步；
- **气泡对照面板**：当前页原文 / 译文逐条对照，点条目高亮页面气泡；
- **竖排**：日漫 RTL 默认竖排（瘦长气泡无论方向都竖排），字距 / 行距独立，
  覆盖层绘制列从右往左；
- **手动微调**：「调整气泡」进微调模式，拖动移动、右下角手柄缩放，落 `<page>.adjust.json`，
  可「恢复自动位置」；滚动模式同样支持（未命中气泡的拖动不消费，列表照常滚动）；
- **跨页气泡合并**：页 N 贴底 × 页 N+1 贴顶、横向重叠 ≥0.5 配对，页 N 翻译时并入续段，
  页 N+1 渲染时以「抹除条目」盖掉原文续段（只在两页都未译时自动合并）；
- **自动裁白边**：四角中位色当底色、行列扫描判定，多页采样并集逐书记忆，渲染期应用。

### 5.5 视觉模型模式

- 入口：漫画菜单「视觉翻译」（本页）/「视觉整卷」（整卷，仅配置了视觉模型或通用模型）；
- 整页图（长边 1024px JPEG q85）直接经 `AiContent.Image` 外发，一次产出气泡框 + 原文 + 译文，
  跳过本地 OCR；
- **逐书**单独确认页图像外发（`aiComicVisionConfirmedBooks`）；台账单独记
  feature=漫画视觉翻译并注明页图像；整卷每页间隔约 1.5s 限速；
- 已知边界：无流式（整页译完一次性上屏）；超长图仍是整页压 1024px 外发（建议走本地 OCR 管线）。

### 5.6 条漫与超长图

- 原生超长图（未预切页，高 ≥ 宽 × 3）：`TallPageTiles` 竖向切片（片高约 2:1、片间重叠 1/4、
  片数封顶 24），逐片跑「RT-DETR + OCR + 归并」，片内坐标换算回整页、按气泡中心归属去重、
  整页重排阅读序；重解 / 切片失败退回压扁整页（检出率差但不出错）；
- 滚动模式气泡微调与翻页布局同一套归一化坐标，无需额外映射。

### 5.7 气泡 inpainting（可选）

- 自定义槽位先行（LaMa 系契约：输入 image + mask、值域 0..1、边长 8 的倍数），官方版未钉；
- ROI = 气泡并集外扩 4%，掩码 4px 膨胀，输入尺寸等比 ≤1024 且 8 对齐，推理后贴回整页；
- **任何失败返回 null**，回落既有采样底色覆盖——功能永远可用；
- 成功时覆盖层不再铺底色块，译文直接落在干净页面上（文字带采样底色描边保持可读）。

## 6. 词典与划词解释

### 6.1 本地查词（离线优先）

- StarDict 三件套（ifo / idx / dict，`.dz` 自动解压）经「设置 → 词典管理」SAF 目录导入到
  `filesDir/dicts/<stem>/`；MDict（.mdx/.mdd）明确报「暂不支持」；
- 解析层纯 JVM：idx 流式索引、UTF-8 无符号字节序二分、大小写三档回落、html 词条剥标签；
- 命中零网络零确认，直接显示释义卡片。

### 6.2 划词解释（回落 AI）

- 本地词典未命中且 AI 已配置时，卡片提供「AI 解释」：词典式 prompt（释义 / 词性 / 例句），
  通用模型流式上屏；首次走 `aiExplainConfirmed` 一次性确认；
- 查词入口的可见性 = `aiConfigured || hasDictionaries`（两者皆无时不出现）；译文视角禁用。

### 6.3 生词本

- 查词卡片「收藏」落 `vocabulary_entries`（词条 / 释义 / 上下文例句 / 来源书与位置 / 时间，
  随书级联）；
- 设置页生词本列表按时间 / 按书分组、逐条删除；
- 导出 Anki 兼容 CSV（单词, 释义, 例句，RFC4180 转义，SAF 另存为）。

## 9. 已知边界与待真机验证

**已知边界**：

- 漫画视觉模式：无流式；超长图仍整页压 1024px 外发；整卷视觉与文本模式共用断点续译判据

- 译文模式下标注写入 / 书签 / 选字翻译 / TTS 禁用（原文坐标系）；
- 双页对照仅双页翻页布局可用，单页 / 悬停 / 滚动自动退出并释放第二分页器（内存不翻倍常驻）；
- Markdown 阅读器不接 TTS / 翻译 / 标注（独立渲染界面）。

**待真机验证**（历次验收记录遗留）：

- int8 气泡模型在 onnxruntime-mobile 精简算子包下的兼容性；
- 自定义 LaMa 模型算子（FFT / ffc 块）兼容与整页抹除耗时；
- NNAPI 开 / 关的整卷翻译耗时与结果一致性；
- 视觉整卷在大页数书上的实际速率与费用；
- 各品牌 SAF / 前台服务 / 通知权限的实际表现。

## 10. 明确不做

- 端侧 LLM 推理（llama.cpp 等：体积与设备覆盖面过不了依赖门槛）；
- 在线 OCR / 云识别（识别永远在本机 ONNX）；
- 机器翻译专用 API（一律走用户配置的 LLM，少一条网络通道）；
- 前文回顾、全书自由问答、人物关系图谱（内容理解类，无限期后置）；
- 漫画 / 扫描件图像增强（inpainting 之外）；
- 在线元数据刮削（豆瓣 / Google Books）——AI 元数据补全是替代路径；
- 任何静默外发：无统计上报、无崩溃上报、无账号体系。
